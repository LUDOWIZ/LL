# LL
Detta repository utgör den tekniska ryggraden i ett sammanlänkat kunskapsträd där metodik, dokumentation och exekvering möts. Systemet är byggt för att stödja resan mot en t-formad kompetens inom IT och kodning.

🌳 Det Sammanlänkande Trädet
Projektet vilar på tre huvudsakliga pelare som samverkar i realtid:

Anytype (Mission Control): Fungerar som det övergripande biblioteket där alla loggar och den strategiska planen för LL förvaras. Det är här de stora dragen dras och där vi länkar samman idéer med utförande.

Obsidian (Workstation): Den operativa basen. Genom en automatiserad Kod-MOC (Map of Content) och en central Dashboard sorteras alla kodsnuttar och tekniska skisser (Excalidraw) automatiskt med hjälp av Dataview.

Coding & GitHub (Execution): Slutstationen där kunskapen blir till verklighet. Genom versionshantering av biblioteket (LL) speglas framstegen från Obsidian direkt till molnet för att bygga en publik portfolio.

📍 Status: Var vi är & Vad vi gjort
Vi har precis avslutat fasen för Infrastrukturell Stabilisering.

Etablerat LL-strukturen: Vi har definierat "LL" som kodnamnet för allt som rör kodning och IT, direkt kopplat till Op. Rainbow Road.

Stabiliserat Kod-MOC: Skapat en felfri, automatiserad motor i Obsidian som sorterar Python, Bash och SQL-snuttar i realtid utan manuell handpåläggning.

Dashboard & Planering: Dashboarden är nu aktiv och redo för morgondagens (24 feb) första tekniska sprint.

GitHub Initialisering: Systemet är nu redo att skickas upp som en helt ny repository för att säkra versionshantering från dag ett.
